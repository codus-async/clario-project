# Clario — Open Decisions and Risk Register (`mvp-open-decisions.md`)

**Document Status:** Stage 3 — Open Decisions and Implementation Risk Register  
**Target Release:** Clario MVP (P0 Scope Only)  
**Purpose:** Records all unresolved policy, academic governance, operational, and compliance decisions from the discovery baseline (`user-strories.md` §10, `features.md` §4, `nfrs.md` §14, `mvp-p.md` §11). In accordance with Source-of-Truth Rule 7, none of these items have been silently invented; each is bounded by configurable hooks in the functional specification until formally resolved by stakeholders.
